# LinkML structural mapping implementation plan

> **For agentic workers:** Use subagent-driven-development with one writer, followed by fresh-context review. Work directly on master, as explicitly requested by the repository owner.

**Goal:** Replace the mapping stubs with faithful Godot data representations and executable regression coverage.

**Architecture:** Small pure mapping functions plus the existing Jinja templates. Preserve the generator's domain-neutral loading/rendering/writing API. No serializer, validator, editor integration or new runtime framework.

**Tech stack:** Python, LinkML SchemaView, Jinja, pytest, Nix-provided Godot and ruff.

**Spec:** `docs/MAPPING.md` (approved structural-projection scope).

## Global constraints

- Godot 4.5+; RefCounted, native abstract classes, no exports.
- Missing scalar values remain null; exact decimal strings; enum string constants.
- All scalar value fields use Variant, while objects and collection elements retain their representable types.
- No silent loss of incompatible inherited storage, unknown types, naming collisions or dynamic enum values.
- Keep generator.py unchanged; adjust test-only mapper/template expectations when required.
- Work and commit directly on master; no branch or worktree creation.
- Stop and ask the owner on any dependency, network, provider, tooling or other non-mapping infrastructure failure. flake.nix may manage tools, but this does not authorize silently troubleshooting failures.
- Functional pytest tests, type hints/docstrings on new functions, no mocks or hidden-error exception handling.

## Preflight consistency review

| Scope | Check |
|---|---|
| Mapping functions ↔ templates | Existing public signatures and Field/EnumMember contexts remain intact; helper additions are shared with the test mapper deliberately. |
| Types ↔ defaults | Variant scalar declarations preserve null; collection element types use underlying representation independently of scalar nullability. |
| Inheritance ↔ constraints | Inherited storage conflicts fail; constraint-only changes are externally validated, never represented as illegal redeclarations. |
| Templates ↔ tests | String constants replace integer enum syntax; the plumbing test changes with that explicit template contract. |
| Tests ↔ docs | Godot smoke test proves actual output runs; 4.7.2 verification is not advertised as a 4.5 test run. |
| Task ↔ scope | One cohesive mapping deliverable, no new runtime codec, validator, editor subsystem or tooling dependency. |

## Verification and review

- Final local suite: 169 tests passed on Python 3.14.8, without skips or xfails.
- Godot 4.7.2 registered the generated classes and emitted `MAPPING_RUNTIME_OK`.
- Ruff lint/format and Git whitespace checks passed.
- Fresh correctness and complexity reviews approved the final fixes.
- Review corrected the interpretation of slot `union_of`: it references slots,
  not ranges, and is explicitly rejected. `any_of` and `exactly_one_of` remain
  supported range unions. Quoted/symbolic defaults and unsupported structural
  expressions are explicitly rejected, as detailed in the mapping contract.
- Python 3.10 and Godot 4.5 were not run locally; the CI configuration was updated,
  but no remote CI result is claimed.
